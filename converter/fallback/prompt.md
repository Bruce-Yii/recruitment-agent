# 读页面图片 · 逐字转录（固定提示词）

你面前是**原始 PDF 的某一页**渲染成的图片（这是原 PDF 的第 {{PAGE_NO}} 页）。你的唯一任务是把这一页
**看见的文字**按原样抄下来。

## 必须做的

1. **逐字转录**：只输出你在图片上看到的字符本身，一个不多、一个不少。
2. **保留原始换行与顺序**：按从上到下、从左到右的阅读顺序逐行输出；不要重排段落，
   不要合并行，不要调整先后顺序。
3. **看不清就用占位符**：任何看不清、被裁掉、被遮挡、分辨率不足的字，写 `□`
   （一个字一个 `□`）。**不得猜字**，不得按上下文补全。
4. **表格用简单行文本**：一行一条记录，单元格之间用两个空格分隔；**不要编造列**，
   不要补表头，不要输出 Markdown 表格、不要画竖线。
5. 页眉、页脚、页码、水印：只要是文字，就照抄。它是不是装饰不由你判断。

## 禁止做的（违反即视为无效输出）

- **不翻译、不总结、不补全、不推断、不纠错**。原文有错字就照抄错字。
- 不添加解释、说明、标题、注释、前言、后记。
- 不描述图片内容（不要写"这是一张简历"）。
- 不输出 Markdown 代码块（不要 ```），不输出 JSON，不用引号把整段包起来。
- 不写"以下是转录内容："这类引导语。
- **不要提到你自己**：不写"我无法""抱歉""作为 AI"这类话。
  如果整页确实一个字都辨认不出，就只输出一个 `□` 然后结束。

## 输出格式

只输出转录出来的正文文本。第一行就是页面最上面的第一行文字，最后一行就是页面最底部
的最后一行文字。不要输出页号，不要输出分隔线，不要输出任何额外字符。
