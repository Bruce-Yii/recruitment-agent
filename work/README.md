# work/ · 决策台账与验收报告

这里放**过程产物**：不做承诺、不长期维护的活文档可以落这里，但**裁决必须回抄进 `docs/`**（以 `docs/` 为权威源）。

## 放什么

| 子目录 | 内容 |
|---|---|
| `work/control/` | 决策台账、裁决备忘、当前执行基线（"为什么这么做"） |
| `work/acceptance/` | 验收报告：E1–E4 证据、converter 语料结果表、分层验收记录（"凭什么说做完了"） |
| `work/research/` | 研究底稿、候选方案比对（"查过什么、为什么没选"） |

## 两条硬规则

1. **报告必须可复跑**：每条结论附命令原文与真实输出，且引用的 fixture / manifest / 报告文件必须在仓库里真实存在（E3）。不接受"测试绿了"当交付。
2. **报告不是权威源**：与 `docs/` 冲突时以 `docs/` 为准；一旦结论变成决定，就写进 `docs/`，否则视为**未决定**。

## 不要放

- 真实候选人资料 / 简历原件 / 会议原文 / 凭据（R7）。
- 大文件语料（合成 PDF 走 `.gitignore`，可重建）。
- 临时脚本（`temp_*.py`）—— 一次性脚本用完即弃，不留档。
