## 1. 这一轮要做什么

把 v4 页面拆出一个**可嵌入模式**：让"右画布"能单独被嵌进外层应用（外层将来是 DSH 的中央面板），而**左栏与对话不出现**。

具体：
1. 支持通过 URL 参数选择模式：
   - `?embed=canvas&application=<id>` → **只渲染右画布**：候选人/岗位画布、确认卡、原件预览入口都在；**不渲染左栏、不渲染 Agent 对话栏**。
   - `?embed=canvas&job=<id>` → 只渲染岗位漏斗画布。
   - 不带参数 → **与现在完全一样**（三栏全在，供独立打开/对照用）。
2. 画布顶部要有一个极简"返回/面包屑"占位区（文字沿用 v4 原有文案，**不新增按钮**）——因为外层会接管返回。
3. 画布宽度自适应外层容器：`100% × 100%`，不出现横向滚动；窄到 700px 时行为与 v4 现有窄屏一致（不给外层加新布局）。
4. 所有数据仍走任务 01 的 `api`（`mock`/`http` 两种模式不变）；**新增接口一律不做**。
