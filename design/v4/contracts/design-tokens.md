## 布局不变量（改这些就是改设计）

| 项 | 值 |
|---|---|
| 三层骨架 | `grid-template-columns: 204px var(--chat-w) 1fr` |
| 左栏展开 / 收起 | **204px / 56px**（收起只留居中图标，无文字） |
| 半屏适配区间 | **700px – 1080px**（窄屏折叠为 56px 图标栏 + 悬浮对话抽屉） |
| 对话栏 | 可拖拽调宽、双击还原、`[` 快捷键收起 |
| 主题 | 暖纸白（`--paper`）+ 纯白（`--surface`），另有暖墨深色模式 |

## 字体与排版

- 字体：`Inter`（400/500/600/700），中文回退系统字体；
- 字号层级与行高以原型 CSS 为准，**迁移时逐条抄，不要"看起来差不多"**。

## 动效

- 列表行悬停"轻滑入"；
- 6 阶段横向进度图"呼吸"；
- 确认卡居中弹出（只读模板，按需点"微调"展开编辑）。

**动效时长/缓动曲线以原型为准**，不新造。
