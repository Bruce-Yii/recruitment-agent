# 设置页（#/settings）导航与渐进式披露设计规范

> **状态**：设计定稿（2026-11-22，总控）  
> **视觉基线**：严格遵守 [`design/v4/design-system-guidelines.md`](./design-system-guidelines.md)（暖纸三层材质 `--rail #F3F2EE` / `--paper #F9F8F5` / `--surface #FFFFFF`、56px 单一顶栏地平线、1px 细线秩序、零嵌套卡片、零彩色大药丸、零禁用词「证据」）  
> **后端复用基线**：`GET /recruitment/api/settings`、`POST /recruitment/api/action/settings/write`（`src/http/settings.ts`，版本链 `appendSettingVersion`，`recruiter` 权限闸门）及 `config/role`、`config/team`、`config/pipeline`（`src/domain/tenant-config.ts`）

---

## 一、设计原则：什么该进设置页，什么不该进？

1. **只放“团队级低频配置与治理策略”**：连接器凭证、自动化开关、催面评规则、组织角色/团队/流程模板、工作说明书与评测只读状态。
2. **不放“高频单人业务动作”**：新建岗位、上传简历、排期、提交面评、决策拍板永远留在队列、岗位页与候选人页，不搬进设置页。
3. **诚实状态，绝不撒谎**：邮箱与飞书连接器状态直接透传服务端真实探活结果（`未配置 / 未连接 / 需重新授权`），未做真实回读绝不显示「已连接」。
4. **交付模型无关**：设置页不把产品绑定到某一家模型厂商，仅在只读区展示当前运行时接入摘要与最近一次 Eval 回归基线状态。

---

## 二、信息架构：单层 4-Tab 导航（无二级侧栏）

入口固定为工作台左栏底部或顶栏右侧低噪齿轮入口，路由 `#/settings`。  
页面采用**与岗位页/候选人页一致的单层 `.canvas-tabs` 横向标签栏**，正文单列最大宽度 `860px`，彻底避免“设置页套二级左侧树”的臃肿后台感：

| Tab | 名称 | 核心职责 | 目标使用者 |
|---|---|---|---|
| **Tab 1** | **连接接入** | 邮箱收发（IMAP 轮询 + SMTP 发件授权）、飞书日历与妙记、外部系统轻量同步（CSV/Webhook 预留） | 招聘负责人 / 管理员 |
| **Tab 2** | **自动化与提醒** | 简历入库自动初筛、转写自动生成面评草稿、**面评催交策略**、候选人自助预约默认参数 | 招聘负责人 |
| **Tab 3** | **组织与招聘规范** | 角色权限视图（`config/role`）、招聘团队成员（`config/team`）、流程阶段与面试模板（`config/pipeline`） | 招聘负责人 / HRBP |
| **Tab 4** | **行为规范与评测** | 只读查看 S6–S10 五套工作说明书当前生效规则、运行时接入摘要、最近一次 Agent Eval 回归基线摘要 | 招聘负责人 / 系统维护者 |

## 三、三层渐进式披露交互模型（L1 → L2 → L3）

为避免“一进设置页满屏输入框”，所有配置项统一遵循三层渐进式披露：

### L1：扫描概览态（默认首屏）
- 以 1px 细线分隔的平铺行呈现（**禁止套卡片再套卡片**）；
- 每行固定 3 要素：**配置项名称** + **1 句人话现状摘要**（如“已开启 · 面试结束 24 小时后提醒”）+ 右侧**轻量开关或「配置」按钮**；
- 顶多 4–6 行就能看完整个 Tab，HR 3 秒内看清全貌。

### L2：行内展开态（点击「配置」后）
- 在当前行下方以 `--surface #FFFFFF` 细线区平滑展开，**不弹遮罩大弹窗**（仅高危操作如“停用模板”或“撤销授权”使用轻量确认条）；
- 只展示 **2–3 个最核心参数**，配清晰默认值与人话说明：
  - 示例（面评催交）：① 超时阈值（`24h / 48h / 72h`）；② 最多提醒次数（默认 `2 次`）；③ 通知通道（工作台置顶 / 飞书消息 / 邮件）；
  - 示例（邮箱收件）：① 收件箱地址；② 自动轮询频率（默认 `5 分钟`）；③ 启用/暂停开关；
  - 示例（候选人自助预约）：① 链接默认有效期（默认 `72 小时`）；② 单次面试默认时长（默认 `60 分钟`）。
- 底部紧贴「取消」与「保存更改」（走统一确认与版本写入，保存后行内收起并刷新 L1 摘要）。

### L3：高级参数折叠态（默认收起）
- 位于 L2 展开区左下角，仅一条低对比度细字链接：**`高级参数 ▸`**；
- 展开后承载低频技术/治理参数，普通 HR 日常完全不接触：
  - 邮箱：IMAP/SMTP Host、端口、TLS 模式、投递文件夹白名单；
  - 催面评：免打扰时段（如 `20:00–09:00`）、节假日顺延开关；
  - 外部同步：Webhook 目标地址、签名密钥轮换、事件订阅列表；
  - 审计：当前配置版本号（`version_no`）与最近修改人/修改时间。

## 五、权限、审计与安全闸门

1. **角色权限**：仅 `recruiter`（招聘负责人）可写入设置；面试官访问 `#/settings` 时自动降级为只读提示或隐藏入口，服务端同步以 `403` / `ALLOWED_ALIASES` 硬拦截。
2. **防伪造与版本审计**：所有 `settings/write` 请求严禁透传 `actor_id / tenant_id / version_no / confirmation_text_sha256` 等服务端派生键（命中即 400 零写入）；每次变更追加不可变版本记录并进入审计链。
3. **术语与测试 ID 纪律**：全页文案通过 `term-lint`（零「证据」）；新增核心交互节点统一登记至 `src/app/TESTID-MANIFEST.md`（前缀 `settings-tab-*` / `settings-row-*` / `settings-expand-*`）。
